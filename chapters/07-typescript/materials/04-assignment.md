## Assignment (unpaid):

Build a simple Task Manager application using TypeScript.

Requirements:

- Create a TypeScript class Task with the following properties:
    - id (number)
    - title (string)
    - description (string)
    - completed (boolean)
- Create a TypeScript class TaskManager with the following methods:
    - addTask(task: Task): void - Adds a task to the task list.
    - getTaskById(id: number): Task | undefined - Returns a task by its ID.
    - markTaskComplete(id: number): void - Marks a task as complete.
    - listAllTasks(): void - Lists all tasks.
- Instantiate the TaskManager class and demonstrate the functionality by:
    - Adding tasks.
    - Listing all tasks.
    - Marking some tasks as complete.
    - Listing all tasks again to verify completion status.
