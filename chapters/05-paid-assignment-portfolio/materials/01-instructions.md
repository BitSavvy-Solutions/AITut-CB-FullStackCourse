# Instructions

## *For the payment amount, please reach out to your mentor.*

## Overview

As part of the Code Blossom curriculum, you will enhance your personal portfolio website using HTML, CSS, and JavaScript. This project will demonstrate your ability to create an interactive and dynamic web experience.

## Requirements

### 1. **Tech Stack:**

- **Frontend:** HTML, CSS, JavaScript (Vanilla JS, no frameworks)
- **Deployment:** Your site must be hosted online using Netlify or GitHub Pages.

### 2. **Functionality:**

- Add interactive elements using JavaScript (e.g., animations, dynamic content, form validation).
- Implement at least three major JavaScript concepts learned in the course.
- Ensure a smooth user experience with an intuitive UI.
- Improve upon your previous static portfolio by making it engaging and interactive.

### 3. **Project Submission:**

- **GitHub Repository:** Upload your full project to GitHub with a clear README file.
- **Live Demo Link:** Provide a working URL to access your deployed portfolio.
- **Video Walkthrough:** Record a short video (3–5 minutes) demonstrating your portfolio’s features and explaining how it works.

## Steps to Complete the Project

### 1. **Plan Your Interactive Portfolio**

- Brainstorm ideas on how to make your portfolio engaging.
- Sketch wireframes and plan interactive elements.
- Set up a meeting with your mentor to discuss your concept and incorporate their feedback.

### 2. **Set Up Your Development Environment**

- Initialize a Git repository and set up version control.
- Push your project to GitHub at the end of each development day.

### 3. **Implement Features**

- Use JavaScript to add interactivity (e.g., modals, animations, dark mode, form validation).
- Ensure a user-friendly design.
- Test the website thoroughly and fix any issues.

### 4. **Deploy Your Portfolio**

- Deploy your website using Netlify or GitHub Pages.
- Ensure all features work correctly in the deployed version.

### 5. **Submit Your Project**

- Upload the source code to GitHub with an updated README.
- Provide the live demo link.
- Record and submit a video walkthrough covering:
    - Overview of your project
    - Key features and interactivity
    - Technical choices and challenges faced
- Share three strategies that helped you learn JavaScript on the #learning Slack channel.
- Once your mentor reviews and signs off on the project, you can claim the completion reward.
- Share a short video about your project on the Slack channel.
